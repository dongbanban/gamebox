# 每次关卡尝试随机生成并保留 runSeed

「狗了个狗」从第 1 关开始不再使用固有关卡快照。用户每次进入、重开或重试关卡时生成新的 `runSeed`，棋盘形状、方块位置、层级、图案、特殊方块分布与锁槽数量均可重新生成；冻结方块、幻化方块、磁吸方块与双生方块的出现、位置、图案和状态同步重新生成，幻化方块的伪装图案与真实图案也同步重新生成。本次尝试内结果保持稳定。

通关奖励沿用现有奖励公式，根据本次生成结果的难度指标计算；随机棋盘仍需落在关卡难度目标范围内。

道具组变更属于局内重置，不属于新关卡尝试；准备态确认初始组后开始本关，挑战进行中不允许换组。失败结果页换组重试当前关卡并沿用原 `runSeed`，通关结果页换组作用于下一关并生成新尝试；换组只重新初始化局内状态与道具次数，不重抽失败重试所沿用的棋盘或特殊机制。

v13 中除钥匙外每种道具每关最多成功使用 1 次；取消、无效目标与失败不扣次。钥匙已选入时初始次数为 0，由任意来源的合格三消按既定配置掉落，次数上限为锁槽数。规则不读取本次尝试的实际随机特殊方块数量，因此同一关重开、重试或变更道具组时保持一致。

离开游戏或刷新页面后，未完成关卡不恢复半局状态；再次进入时生成新的关卡尝试与新的 `runSeed`。

v13 关卡配置固定本关允许的特殊机制类型；先按逻辑方块总数 `N` 计算 `floor(N × 0.30)` 特殊机制逻辑单位预算，再按冻结/幻化/磁吸权重 1、双生权重 2 分配数量。当前 1–5、6–15、16–30、31–99 预算分别约为 27、32–37、43–54、54 个逻辑单位，特殊方块数量随 `N` 同步提高；锁槽数量按本次 `runSeed` 随机为 0–2。总特殊机制密度按逻辑方块单位校验，双生计 2、其他方块机制计 1；v13 目标贴近且不超过 30%，锁槽不计入密度但进入容量压力、无道具求解与难度指标。生成完成后必须验证结构、三消数量、所有机制组合、锁槽容量、逻辑单位、无道具可解性与难度目标；磁吸目标随机与钥匙掉落随机使用独立派生流。不合格候选重抽，受控 fallback 也必须通过验证。v13 不再提供旧生成器策略兼容入口。

关卡逻辑不得直接依赖未保存的 `Math.random()` 状态。系统可用运行时随机源生成 `runSeed`，随后使用可复现的 seeded random 完成全部关卡生成。

生成允许在进入、重开或重试时显示短暂加载；下一关优先在当前关卡进行期间后台预生成，复杂计算放入 Web Worker，避免阻塞主线程。加载超时只能使用已通过验证的受控 fallback，不得展示未验证候选。

特殊机制与道具使用以对应视觉效果表达状态与结果，不强制增加文字状态提示。幻化与双生棋盘视角使用普通方块样式，不显示常驻特殊标记；幻化揭示、磁吸吸引、消磁、双生分裂、锁槽解锁与钥匙掉落使用明确反馈。动画时序由 v13 集中配置，QA 校验输入锁、结算顺序与结果一致性。
