# 每次关卡尝试随机生成并保留 runSeed

「狗了个狗」从第 1 关开始不再使用固有关卡快照。用户每次进入、重开或重试关卡时生成新的 `runSeed`，棋盘形状、方块位置、层级、图案、特殊方块分布与锁槽数量均可重新生成；冻结方块、幻化方块、磁吸方块与双生方块的出现、位置、图案和状态同步重新生成，幻化方块的伪装图案与真实图案也同步重新生成。本次尝试内结果保持稳定。

通关奖励沿用现有奖励公式，根据本次生成结果的难度指标计算；随机棋盘仍需落在关卡难度目标范围内。

道具组变更属于局内重置，不属于新关卡尝试；准备态确认初始组后开始本关，挑战进行中不允许换组。失败结果页换组重试当前关卡并沿用原 `runSeed`，通关结果页换组作用于下一关并生成新尝试；换组只重新初始化局内状态与道具次数，不重抽失败重试所沿用的棋盘或特殊机制。

普通道具与消磁仪次数基础范围为每种道具每关 1–2 次；特殊机制数量上限或密度较高的关卡可按关卡配置提高对应道具次数。钥匙已选入时初始次数为 0，由任意来源的合格三消按阶段配置命中率掉落，次数上限为锁槽数。提高值不读取本次尝试的实际随机数量，因此同一关重开、重试或变更道具组时保持一致。

离开游戏或刷新页面后，未完成关卡不恢复半局状态；再次进入时生成新的关卡尝试与新的 `runSeed`。

关卡配置固定本关允许的特殊机制类型；每种方块机制独立配置按关卡进度档位解析的 `min/max` 数量范围：冻结、磁吸、双生使用 1–2、2–3、2–4、3–4 四档，幻化使用 1–2、2–3、3–4、3–5 四档；锁槽数量按本次 `runSeed` 随机为 0–2。`runSeed` 只在该集合内随机各机制的数量、位置、图案、状态与锁槽数量。总特殊机制密度按逻辑方块单位校验，双生计 2、其他方块机制计 1；锁槽不计入 6% 方块机制密度，但进入容量压力、无道具求解与难度指标。关卡生成完成后必须重新验证结构约束、三消数量、所有已启用特殊机制及其组合、锁槽容量、逻辑方块权重、无道具可解性与难度目标；难度指标、解法搜索与预估时长必须模拟实际特殊机制。磁吸目标随机与钥匙掉落随机从同一 `runSeed` 派生独立流，避免一种事件改变另一种事件的回放序列。不合格候选重抽，超过上限使用受控 fallback。一个关卡可以同时启用多种特殊机制，未来新增机制必须接入同一候选验证流程；单个方块暂不允许叠加多个特殊机制。

关卡逻辑不得直接依赖未保存的 `Math.random()` 状态。系统可用运行时随机源生成 `runSeed`，随后使用可复现的 seeded random 完成全部关卡生成。

生成允许在进入、重开或重试时显示短暂加载；下一关优先在当前关卡进行期间后台预生成，复杂计算放入 Web Worker，避免阻塞主线程。加载超时只能使用已通过验证的受控 fallback，不得展示未验证候选。

特殊机制与道具使用以对应视觉效果表达状态与结果，不强制增加文字状态提示。所有特殊机制方块持续显示静态识别动效；磁吸吸引、消磁、双生分裂、锁槽解锁与钥匙掉落使用明确动效。沿用现有方块飞入与三消反馈时序；新增道具动画首版使用统一时长基准，后续通过试玩微调。
