# 幻化与双生方块采用普通棋盘视觉，保留入槽反馈

v13 中，幻化方块与双生方块在棋盘上的视角效果与普通方块一致。幻化仍可显示由关卡尝试生成的伪装图案，但不再使用 fuzzy、mask、常驻识别动效或必须文字；双生不再显示棋盘常驻双生标记。机制说明缩略图同样使用普通方块视觉。

两类机制的规则信息不被视觉简化：幻化直接点击后在飞入暂存槽过程中揭示真实图案，检测仪继续支持原位揭示；双生进入暂存槽后播放分裂反馈并生成两个相邻普通方块；磁吸吸入双生时复用该分裂反馈。动效属于一次入槽原子操作的一部分，不改变逻辑方块单位、求解、失败或回放语义。

## Considered Options

- 保留棋盘常驻特殊动效：识别成本低，但削弱伪装与判断压力，不符合 v13 难度目标。
- 删除所有入槽反馈：视觉状态不完整，玩家无法理解幻化揭示与双生容量变化。
- 用额外文字替代视觉反馈：增加界面噪声，且不符合现有不依赖强制状态文案的交互约束。

## Consequences

- 渲染层必须把棋盘视觉与机制状态解耦；机制状态仍进入生成、求解、运行时与回放。
- 视觉测试锁定可观察的普通棋盘样式、入槽揭示/分裂时序与输入锁，不锁定具体 CSS 或单帧像素。
- 机制说明缩略图不能复用带常驻特殊标记的棋盘展示。
