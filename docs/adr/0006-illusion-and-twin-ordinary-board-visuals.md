# 幻化与双生方块在棋盘使用普通方块视觉

v13 中，幻化方块与双生方块在棋盘展示层完全使用普通方块视觉：不输出特殊视觉 class，不显示特殊边框、阴影、遮罩、fuzzy、常驻识别动效或机制图标。幻化仍显示由关卡尝试生成的伪装图案；伪装图案是玩法信息，不属于特殊装饰。机制 data attrs 仍可供目标选择、运行时与测试识别。机制说明缩略图使用普通方块视觉，不复用棋盘特殊视觉类。

两类机制的规则信息不被视觉简化：幻化直接点击后先飞入暂存槽，飞行期间保持伪装图案且不显现真实图案，入槽完成后才揭示真实图案；检测仪继续支持原位揭示。双生进入暂存槽后播放分裂反馈并生成两个相邻普通方块；磁吸吸入双生时复用该分裂反馈。棋盘普通视觉不影响暂存槽中的揭示/分裂反馈。动效属于一次入槽原子操作的一部分，不改变逻辑方块单位、求解、失败或回放语义。

## Considered Options

- 仅停用棋盘 pulse：不能移除由 special class 驱动的伪元素、fuzzy、mask 与双生“2”图标，仍会让棋盘方块区别于普通方块。
- 移除机制语义 data attrs：可让视觉变普通，但会破坏目标选择、运行时渲染与测试识别边界。
- 保留棋盘特殊视觉：识别成本低，但削弱伪装与判断压力，不符合 v13 视觉收口要求。
- 删除所有入槽反馈：视觉状态不完整，玩家无法理解幻化揭示与双生容量变化。
- 用额外文字替代视觉反馈：增加界面噪声，且不符合现有不依赖强制状态文案的交互约束。

## Consequences

- 渲染层必须把棋盘视觉 class/glyph 与机制状态解耦；幻化/双生保留机制 data attrs 与幻化伪装图案，但棋盘输出普通方块 class/glyph，不显示专属伪元素、常驻动效或图标。冻结、磁吸等仍需识别的机制继续使用各自视觉。
- 视觉测试锁定棋盘使用普通方块 class/glyph、无特殊伪元素/常驻动效/图标，同时保留机制 data attrs、幻化伪装图案、普通缩略图及入槽揭示/分裂时序与输入锁，不锁定具体 CSS 或单帧像素。
- 机制说明缩略图不能复用带常驻特殊标记的棋盘展示。
