# 幻化与双生方块恢复持续特殊视觉动效

v13 中，幻化方块与双生方块在棋盘及机制说明缩略图恢复原有持续特殊视觉动效。幻化显示由关卡尝试生成的伪装图案，并复用特殊边框、阴影、mask/fuzzy 与 pulse；双生复用特殊边框、阴影、pulse 与“2”标记。机制 data attrs 继续供目标选择、运行时与测试识别；系统减少动态效果时关闭非必要动画。

两类机制的规则不变：幻化直接点击后先飞入暂存槽，飞行期间保持伪装图案且不显现真实图案，入槽完成后才揭示真实图案；检测仪继续支持原位揭示。双生进入暂存槽后播放分裂反馈并生成两个相邻普通方块；磁吸吸入双生时复用该分裂反馈。持续识别动效不改变逻辑方块单位、求解、失败或回放语义。

## Considered Options

- 继续使用普通方块视觉：棋盘更简洁，但玩家无法在点击前识别双生的双倍槽位影响，机制说明也不能预览真实效果。
- 移除机制语义 data attrs：会破坏目标选择、运行时渲染与测试识别边界。
- 删除所有入槽反馈：视觉状态不完整，玩家无法理解幻化揭示与双生容量变化。
- 用额外文字替代视觉反馈：增加界面噪声，且不符合现有不依赖强制状态文案的交互约束。

## Consequences

- 渲染层为棋盘与机制说明缩略图复用幻化/双生 special class；幻化额外输出 fuzzy glyph 与伪装图案资源，机制 data attrs 保持不变。
- 视觉测试锁定 special class、幻化 fuzzy/mask 入口、双生标记及入槽揭示/分裂时序与输入锁，不锁定具体 CSS 或单帧像素。
- `prefers-reduced-motion` 继续关闭持续动画，不移除用于识别机制的静态样式。
