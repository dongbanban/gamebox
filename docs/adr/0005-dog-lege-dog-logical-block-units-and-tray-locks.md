# 「狗了个狗」特殊机制按逻辑方块单位建模，锁槽作为容量机制

「狗了个狗」采用逻辑方块单位统一表达双生分裂、磁吸入槽、三消配额、暂存槽压力与无道具可解性：普通、冻结、幻化、磁吸方块各计 1 个单位，双生方块计 2 个单位；棋盘层叠仍按实际棋盘对象计算。锁槽属于关卡级容量机制，不计入方块机制密度，但会减少有效容量并进入求解与难度指标。选择这套双重计量，是因为物理棋盘对象无法表达双生入槽后的两个方块，而把锁槽当作方块机制又会污染机制密度；同时，双生或磁吸导致的容量风险保留为玩家判断，不增加自动禁点或安全拦截。

## Considered Options

- 只按棋盘物理对象计数：无法保持双生后的图案三消配额与容量压力一致。
- 把锁槽计入特殊方块密度：会把关卡容量规则与棋盘机制混为一类，导致密度与难度指标失真。
- 在双生/磁吸可能造成失败前自动禁用点击：会替玩家承担本应属于策略判断的风险，改变基础失败规则。

## Consequences

- 关卡生成器、无道具求解器、`GameSession` 与难度指标必须共享逻辑方块单位语义。
- 任何新增改变入槽数量的机制都必须声明逻辑单位权重，并进入同一候选验证流程。
- 运行时允许短暂出现由原子特殊机制操作产生的超容量结果；结算完成后按有效容量判定失败，不提前替玩家拦截。
