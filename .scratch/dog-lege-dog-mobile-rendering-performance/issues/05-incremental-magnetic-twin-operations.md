# 05 — 磁吸与双生原子操作保持增量

**What to build:** 玩家选择磁吸或双生方块时，棋盘和暂存槽只增删原子操作真实涉及的节点，同时保留目标选择、分裂、容量压力、三消与输入锁规则。

**Blocked by:** 03 — 三消、锁槽与容量变化保持增量

**Status:** ready-for-agent

- [ ] 磁吸方块进入暂存槽时只移除自身棋盘节点，并在存在合法目标时只移除被吸目标节点。
- [ ] 磁吸自身与目标按 session 决定的顺序进入暂存槽，未参与操作的棋盘方块和槽位保持原节点。
- [ ] 被吸方块保留自身机制并按自身入槽规则处理，幻化揭示、双生分裂及冻结状态不会因增量更新丢失。
- [ ] 磁吸吸引和目标飞行动画继续使用操作前捕获的位置，完成前保持输入锁。
- [ ] 消磁仪只更新目标磁吸方块的机制属性与静态视觉，不重建全部棋盘。
- [ ] 双生方块选择后只移除一个棋盘节点，并在暂存槽中新增两个独立、相邻且稳定 ID 的普通方块节点。
- [ ] 双生分裂造成三消、满槽或超容量时，最终节点与失败判定保持现有原子结算语义。
- [ ] 磁吸或双生操作触发三消时复用 ticket 03 的增量暂存槽路径，不增加机制专属全量 renderer。
- [ ] 通过公开游戏入口覆盖有/无磁吸目标、被吸特殊方块、消磁仪、普通双生及磁吸双生组合。
- [ ] 运行 `pnpm test:ui` 并记录结果；本 ticket 不运行完整 QA、affected 或 focused profile。
