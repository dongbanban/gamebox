# 01 — 收敛特殊方块常驻动效

**What to build:** 移动端和桌面端玩家继续看得懂特殊机制，但棋盘、暂存槽与机制说明不再运行已确认删除的高负载常驻动效，从而降低活动关卡静置时的持续浏览器负载。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 幻化方块继续显示伪装图案、静态特殊样式、遮罩与模糊本体，不再运行整块脉冲、图像抖动或两层横向切片动画。
- [x] 棋盘与暂存槽中的冻结、双生、磁吸及乱序状态不再运行作用于整个方块或槽位的无限脉冲、呼吸或闪烁。
- [x] 既有右下角雪花、“2”、磁铁等机制标记保持可见并采用静态高亮，标记自身不运行无限动画。
- [x] 乱序方块在棋盘上继续采用普通方块视觉，进入暂存槽后仍可通过静态状态样式和状态文案识别 armed、triggerable 与 consumed。
- [x] 机制说明缩略图遵守相同识别规则：幻化只保留遮罩与模糊本体，双生保留静态“2”标记，其他缩略图不恢复常驻脉冲。
- [x] `prefers-reduced-motion: reduce` 关闭剩余幻化遮罩与模糊本体动画，同时保留伪装图案、静态边框和机制标记。
- [x] 飞入、揭示、分裂、吸引、融化、三消、乱序结算、复原、道具、通关和失败等一次性反馈保持原时序与结果。
- [x] 删除已无消费者的无限动画定义、样式变量及动画时长配置；集中配置中不保留无效字段，也不增加替代开关。
- [x] 更新 ADR-0006 与领域文档，明确 pulse 决策被移动端负载证据覆盖，特殊机制规则与 data attrs 不变。
- [x] 通过公开游戏入口和浏览器可观察样式验证常驻动画集合及静态机制标记，不断言具体 CSS 文件结构。
- [x] 运行 `pnpm test:ui` 并记录结果；本 ticket 不运行完整 QA、affected 或 focused profile。
