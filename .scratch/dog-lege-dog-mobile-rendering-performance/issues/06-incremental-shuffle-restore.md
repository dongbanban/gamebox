# 06 — 乱序与复原保持暂存槽节点

**What to build:** 乱序与复原哨改变暂存槽顺序时，游戏移动既有方块节点而不是重新创建全部槽位，并继续正确表达状态、事务与输入锁。

**Blocked by:** 03 — 三消、锁槽与容量变化保持增量

**Status:** ready-for-agent

- [ ] 乱序状态变化只同步对应方块的状态属性、静态样式和状态文案，不恢复整槽无限脉冲。
- [ ] 乱序实际改变顺序时，暂存槽按最终顺序移动既有方块节点，稳定方块 ID 与节点身份保持。
- [ ] 乱序结果为稳定原序时不发生无意义的槽位结构替换。
- [ ] 乱序触发后的三消、钥匙掉落和冻结进度继续使用最终 session snapshot，并复用增量暂存槽路径。
- [ ] 复原哨成功使用时按事务快照恢复既有方块顺序和机制进度，只新增、删除或移动真实有差异的节点。
- [ ] 触发乱序的方块在复原后继续保留并转为普通方块，复原哨次数不回滚。
- [ ] 稳定原序、终局或事务失效时复原哨仍不可用，增量 renderer 不保留陈旧的可用状态。
- [ ] 乱序结算与复原一次性反馈、输入锁及可访问状态保持现有时序。
- [ ] 通过公开游戏入口覆盖 reordered、stable、armed、triggerable、consumed、成功复原和不可复原路径。
- [ ] 运行 `pnpm test:ui` 并记录结果；本 ticket 不运行完整 QA、affected 或 focused profile。
