# 08 — 动画、音效与响应式体验

**What to build:** 用户在移动端与桌面端都能获得完整的方块移动、三消、结果与音效反馈，同时不破坏已确认的游戏状态。

**Blocked by:** 04 — 通关奖励与游戏进度持久化

**Status:** ready-for-agent

- [ ] 点击方块后播放飞入暂存槽动画；动画期间锁定输入，动画结束后开放下一次操作。
- [ ] 三消、通关、失败拥有独立视觉反馈；动画关闭或中断不改变已确认的游戏结果。
- [ ] 方块使用统一风格 SVG 图案；游玩中不显示狗名称文字。
- [ ] 粒子、彩带等效果使用独立 Canvas 层，不改变 `GameSession` 规则状态。
- [ ] 点击、三消、通关、失败拥有音效；音效在首次用户操作后初始化。
- [ ] 静音设置可以切换并在刷新后保留。
- [ ] 移动端竖屏自动缩放棋盘，不支持棋盘滚动、拖拽或缩放。
- [ ] 桌面端棋盘居中并限制最大宽度；鼠标与触摸使用统一 Pointer Events。
- [ ] 页面不展示倒计时、难度分或本局用时；内部调试统计仍可记录时长。
- [ ] 动画测试验证输入锁、最终状态、下层解锁与结果出现，不绑定每帧或像素细节。
