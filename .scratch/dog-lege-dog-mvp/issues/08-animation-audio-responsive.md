# 08 — 动画、音效与响应式体验

**What to build:** 用户在移动端与桌面端都能获得完整的方块移动、三消、结果与音效反馈，同时不破坏已确认的游戏状态。

**Blocked by:** 04 — 通关奖励与游戏进度持久化

**Status:** done

- [x] 点击方块后播放飞入暂存槽动画；动画期间锁定输入，动画结束后开放下一次操作。
- [x] 三消、通关、失败拥有独立视觉反馈；动画关闭或中断不改变已确认的游戏结果。
- [x] 方块使用统一风格 SVG 图案；游玩中不显示狗名称文字。
- [x] 粒子、彩带等效果使用独立 Canvas 层，不改变 `GameSession` 规则状态。
- [x] 点击、三消、通关、失败拥有音效；进入活动游戏时沿启动点击链初始化并尝试播放，首次方块操作可重试被浏览器拒绝的播放。
- [x] 静音设置可以切换并在刷新后保留。
- [x] 移动端竖屏自动缩放棋盘，不支持棋盘滚动、拖拽或缩放。
- [x] 桌面端棋盘居中并限制最大宽度；鼠标与触摸使用统一 Pointer Events。
- [x] 页面不展示倒计时、难度分或本局用时；内部调试统计仍可记录时长。
- [x] 动画测试验证输入锁、最终状态、下层解锁与结果出现，不绑定每帧或像素细节。

## Comments

- 使用 Pointer Events、CSS/Web Animations、独立 Canvas 粒子层与 Web Audio；GameSession 先确认结果，动画取消不撤销已持久化通关。
- 静音设置接入 ProgressStore；移动端/桌面端棋盘布局加入 Chromium E2E。
- 验证通过：`pnpm typecheck`、`pnpm test`（44 tests）、`pnpm build`、`pnpm test:e2e`（6 Chromium tests）。
