# 04 — 通关奖励与游戏进度持久化

**What to build:** 用户完成或失败一关后看到结果；首次通关获得基于难度的奖励并解锁下一关；刷新后游戏目录保留正确进度。

**Blocked by:** 03 — 完成堆叠三消核心局

**Status:** done

- [x] 通关后立即记录关卡完成、首次通关奖励与下一关解锁，再展示通关结果。
- [x] 新用户从第 1 关开始；完成第 N 关后最高解锁关卡推进到至少第 N+1 关。
- [x] 重玩已完成关卡不重复累计通关奖励，也不降低最高解锁关卡。
- [x] 通关页展示当前关卡、通关奖励、累计积分、下一关与返回列表操作。
- [x] 失败页展示当前关卡、重新挑战与返回列表操作。
- [x] 刷新或重新进入游戏后，进度与累计积分从本地状态恢复。
- [x] 通过 `ProgressStore` 公共 seam 覆盖首次完成幂等、多游戏隔离与进度恢复。

## Comments

- 新增 `ProgressStore.recordLevelCompletion`：首次完成记录 `completedLevels`、奖励、最高解锁关卡；重复完成幂等；不同游戏独立保存。
- 游戏模块通过结果回调通知通关/失败；公共层先写进度，再展示通关或失败页。通关页展示当前关卡、奖励、累计积分、下一关；失败页支持重新挑战与返回游戏目录。
- 旧版缺少 `completedLevels` 的有效状态按线性解锁进度恢复完成历史；临时存储结果页显示持久化警告。
- 验证通过：`pnpm typecheck`、`pnpm test`（23 tests）、`pnpm build`、`pnpm test:e2e -- --project=chromium`（2 tests）。
