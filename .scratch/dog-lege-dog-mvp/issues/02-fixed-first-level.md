# 02 — 进入「狗了个狗」稳定首关

**What to build:** 用户点击游戏目录中的「狗了个狗」后进入稳定第 1 关，看到完整长方形可见棋盘、内部不规则逻辑轮廓与层叠方块，游戏模块可被公共层启动。

**Blocked by:** 01 — 注册与游戏目录首条闭环

**Status:** done

- [x] 游戏目录卡片可以打开「狗了个狗」游戏模块。
- [x] 第 1 关通过统一生成器的首关 profile 使用 90 个方块、6 种图案与最多 3 层；可见棋盘为完整长方形。
- [x] 方块使用 `4×4` 逻辑细格、整数 `x/y/z`、不旋转；内部不规则逻辑轮廓外没有可玩方块。
- [x] 同一层方块无正面积重叠；方块具有稳定的层级与图案类型。
- [x] 游戏模块暴露公共启动与状态读取 seam，公共层不依赖游戏内部规则。
- [x] 用户可以从首页进入游戏并返回游戏目录，不要求先完成游玩逻辑。

## Comments

- 新增稳定首关 profile 与 `startDogLegeDogGame` / `getState` 公共 seam；首关通过统一生成器提供，目录项注入 launcher，公共层按游戏 ID 路由。
- 首关验证：90 个方块、6 个固定图案类型、3 层、4×4 逻辑细格、不规则内部轮廓、完整长方形可见表面、同层无正面积重叠与稳定 seed。
