# 02 — 进入「狗了个狗」固定首关

**What to build:** 用户点击游戏目录中的「狗了个狗」后进入固定第 1 关，看到真实棋盘形状与层叠方块，游戏模块可被公共层启动。

**Blocked by:** 01 — 注册与游戏目录首条闭环

**Status:** done

- [x] 游戏目录卡片可以打开「狗了个狗」游戏模块。
- [x] 第 1 关固定使用长方形棋盘、90 个方块、4 种图案与最多 3 层。
- [x] 方块使用 `2×2` 逻辑小格、整数 `x/y/z`、不旋转；形状外没有可玩方块。
- [x] 同一层方块无正面积重叠；方块具有稳定的层级与图案类型。
- [x] 游戏模块暴露公共启动与状态读取 seam，公共层不依赖游戏内部规则。
- [x] 用户可以从首页进入游戏并返回游戏目录，不要求先完成游玩逻辑。
