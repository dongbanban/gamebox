# 06 — 确定性关卡模板与进度曲线

**What to build:** 第 2 关起由稳定 seed 生成可加载的关卡，形状、图案、方块数量与层数随关卡进度变化，并遵守棋盘结构不变量。

**Blocked by:** 05 — 关卡选择与离开保护

**Status:** done

- [x] 同一游戏、生成器版本与关卡号始终生成同一棋盘；不使用 `userId` 或当前时间参与 seed。
- [x] 形状模板包含长方形、五角星形、爱心形与不规则形，每类支持多个预定义网格变体。
- [x] 形状池按阶段开放：第 1–5 关长方形；第 6–15 关长方形/五角星形；第 16–30 关增加爱心形；第 31 关起开放四类并按难度加权。
- [x] 方块数量按 90、108、126、144、162、180 阶段递增并封顶。
- [x] 最大层数按 3、4、5、6 阶段递增。
- [x] 图案池使用十种已确认狗主题图案；图案数量按 4、6、8、10 种阶段开放。
- [x] 整关每种图案总数为 3 的倍数；局部区域可任意分布。
- [x] 同层无正面积重叠；单个下层方块最多被 4 个上层方块遮挡。
- [x] `LevelGenerator` 公共 seam 可通过明确的关卡号、seed 与生成器版本取得结果。
