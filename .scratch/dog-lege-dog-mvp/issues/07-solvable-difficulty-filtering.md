# 07 — 无道具可解生成与难度筛选

**What to build:** 无限关卡不会因为随机摆放先天无解；生成器按阶段目标筛选策略压力与游玩时长，并在筛选失败时安全降级。

**Blocked by:** 06 — 确定性关卡模板与进度曲线

**Status:** ready-for-agent

- [ ] 生成器先构造合法消除路径，再反向叠放方块并回放验证。
- [ ] 每个候选关卡至少存在一条不依赖道具的通关路径。
- [ ] 生成器计算方块数量、最大层数、遮挡率、安全选择、暂存槽峰值压力、形状复杂度与图案种类等难度指标。
- [ ] 安全选择目标符合阶段：前期至少 3 个，中期通常至少 2 个，后期允许 1–2 个。
- [ ] 目标时长符合阶段区间：前期 6–8 分钟，中期 7–9 分钟，后期 8–10 分钟，高难度 8–12 分钟。
- [ ] 候选筛选最多重试 100 个 seed；没有完全命中时选择最接近且仍可解的候选，并逐步放宽筛选区间。
- [ ] 筛选失败不会返回无解棋盘或造成白屏。
- [ ] 失败案例记录关卡号、关卡 seed、测试 seed 与生成器版本，可单独重放。
- [ ] 生成器公共 seam 覆盖可解性、安全选择、难度区间与降级策略。
