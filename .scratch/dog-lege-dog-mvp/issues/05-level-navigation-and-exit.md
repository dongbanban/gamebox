# 05 — 关卡选择与离开保护

**What to build:** 用户可以继续当前进度、选择已解锁关卡重玩，并在离开活动关卡前确认；半局始终不保存。

**Blocked by:** 04 — 通关奖励与游戏进度持久化

**Status:** done

- [x] 进入游戏默认打开当前最高解锁关卡。
- [x] 已解锁关卡可选择并重玩；未解锁关卡显示锁定。
- [x] 重玩旧关不会重复发放通关奖励。
- [x] 应用返回与浏览器后退在活动关卡中触发离开确认。
- [x] 确认离开后返回游戏目录并丢弃半局；取消后继续游戏。
- [x] 刷新、关闭或离开半局不写入局内状态、进度或积分。

## Comments

- 新增关卡选择器：默认启动最高解锁关卡，展示已解锁关卡与锁定关卡；当前已选关卡点击不重启半局，切换关卡先确认。
- 新增应用返回与浏览器后退离开保护；取消恢复活动关卡，确认返回游戏目录；局内 `GameSession` 只存在内存，不写入 `ProgressStore`。
- 验证通过：`pnpm typecheck`、`pnpm test`（26 tests）、`pnpm build`、`pnpm test:e2e -- --project=chromium`（5 tests）。
- 后续关卡生成与难度模板仍由票据 06 负责；本票据提供导航所需的稳定关卡身份。
