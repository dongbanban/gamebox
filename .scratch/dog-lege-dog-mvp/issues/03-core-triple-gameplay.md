# 03 — 完成堆叠三消核心局

**What to build:** 用户可以选择可点击方块，将方块放入 7 格暂存槽，完成三消；错误选择导致失败，清空棋盘导致通关。

**Blocked by:** 02 — 进入「狗了个狗」固定首关

**Status:** done

- [x] 只有不存在更高层活动方块正面积重叠的方块可点击。
- [x] 边缘或角点接触不构成遮挡；更高层任意正面积重叠都会阻挡下方方块。
- [x] 点击方块后，方块进入暂存槽；同类方块插入已有同类后方，新图案插入末尾。
- [x] 暂存槽最多 7 个位置。
- [x] 三个相同图案类型自动消除；同次操作产生的多组三连全部处理。
- [x] 暂存槽短暂达到 7 个但立即触发三消时不失败。
- [x] 暂存槽满且无法继续消除时进入失败状态。
- [x] 棋盘方块全部清空时进入通关状态。
- [x] 通过 `GameSession` 公共行为 seam 覆盖可点击判定、暂存槽、三消、通关与失败。
