# 08 — 道具三消移除

**What to build:** 落地以暂存槽内相邻普通同图案方块对为目标的三消移除道具；系统只从棋盘补充一个同类普通方块，完成一次完整三消。

**Blocked by:** 04 — 需要统一道具执行、次数和输入锁；基础暂存槽三消规则由现有游戏逻辑提供。

**Status:** done

- [x] 目标必须是暂存槽中两个相邻、同图案、无特殊机制的方块；暂存槽只有一个同类方块或同类方块不相邻时不能使用。
- [x] 不再支持槽内一个同类方块自动补两个；合法方块对只从棋盘自动补一个当前可点击的同图案普通方块，补充方块不回到暂存槽，而是与选中的槽内方块一起移除。
- [x] 三消移除只处理用户选中的暂存槽相邻方块对与一个棋盘补充方块；一次完整移除恰好 3 个同类方块。
- [x] 系统自动选择补充方块；候选只允许当前可点击方块，同类候选按稳定的关卡顺序选取，不使用额外随机。
- [x] 所有补充方案先过滤无道具可解性；只有至少保留一条无道具通关路径的方案才可执行。
- [x] 无法补齐、会破坏可解性或目标不合法时使用失败，不扣次数，不改变棋盘和暂存槽。
- [x] 成功后播放棋盘补充与三消移除动画；动画期间锁定输入，结算后重新检查暂存槽与关卡状态。
- [x] 该道具不改变其他方块特殊状态，不允许撤销；成功扣 1 次。
- [x] 增加相邻目标对、非相邻拒绝、自动补一个、可解性过滤、失败原子性、动画及次数测试。
