# 08 — 道具三消移除

**What to build:** 落地以暂存槽已有图案为目标的三消移除道具；系统自动从棋盘补齐同类方块，完成一次完整三消。

**Blocked by:** 04 — 需要统一道具执行、次数和输入锁；基础暂存槽三消规则由现有游戏逻辑提供。

**Status:** done

- [x] 目标必须是暂存槽中已有的普通图案；暂存槽中没有该图案时不能使用。
- [x] 暂存槽已有 1 个同类方块时，系统自动从棋盘补 2 个；已有 2 个时补 1 个；补充方块不回到暂存槽，而是与槽内方块一起移除。
- [x] 三消移除只处理暂存槽内连续相邻的 3 个同类方块；一次完整移除恰好 3 个同类方块。
- [x] 系统自动选择补充方块；候选只允许当前可点击方块，同类候选按稳定的关卡顺序选取，不使用额外随机。
- [x] 所有补充方案先过滤无道具可解性；只有至少保留一条无道具通关路径的方案才可执行。
- [x] 无法补齐、会破坏可解性或目标不合法时使用失败，不扣次数，不改变棋盘和暂存槽。
- [x] 成功后播放棋盘补充与三消移除动画；动画期间锁定输入，结算后重新检查暂存槽与关卡状态。
- [x] 该道具不改变其他方块特殊状态，不允许撤销；成功扣 1 次。
- [x] 增加数量补齐、自动选取优先级、可解性过滤、失败原子性、动画及次数测试。
