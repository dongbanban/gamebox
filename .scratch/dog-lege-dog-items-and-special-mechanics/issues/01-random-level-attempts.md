# 01 — 随机生成关卡尝试与 runSeed

**What to build:** 从第一关开始，每次进入、重开、重试都生成新的随机关卡尝试；系统先验证关卡，再让玩家看到棋盘。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 第一关不再使用固定棋盘；每次新尝试生成新的 `runSeed`，并用该 seed 决定棋盘形状、位置、层级及普通图案。冻结、幻化等特殊机制接入由 03、05 ticket 负责。
- [x] 同一 `runSeed` 与生成器版本可以复现同一棋盘、解法路径及奖励公式所需输入；不同尝试允许产生不同棋盘与解法。特殊方块状态复现由对应机制 ticket 验证。
- [x] 关卡生成使用可复现的 seeded PRNG；关卡逻辑不直接依赖未记录的裸 `Math.random`。
- [x] 生成候选在展示前完成结构、三消数量、当前普通方块规则、无道具可解性、难度及预计时长验证；失败候选丢弃，兜底候选也必须验证。特殊机制接入后复用该验证 seam。
- [x] 当前普通方块规则下，`可解关卡` 至少存在一条不使用道具的通关路径；冻结自然融化由 03 ticket 验证，幻化点击揭示由 05 ticket 验证。
- [x] 离开、刷新、重开、重试不保留当前未完成尝试的半状态；重新进入未完成关卡生成新尝试，同时保留已确认道具组与公共进度。
- [x] 现有奖励公式保持不变；随机生成的难度指标作为现有公式输入，不新增重复通关奖励规则。
- [x] 增加生成器、seed 复现、随机回归、无道具解法验证测试，并记录实际验证命令与结果。
