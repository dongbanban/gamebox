# 05 — 幻化方块与飞入暂存槽时揭示

**What to build:** 落地只存在于棋盘的幻化方块；它在棋盘上伪装成其他图案，点击后飞入暂存槽途中显现真实图案。

**Blocked by:** 01 — 幻化状态由随机关卡尝试生成；03 — 特殊机制需要共享方块状态与无道具求解规则。

**Status:** ready-for-agent

- [ ] 幻化方块只出现在棋盘，不进入关卡配置之外的暂存槽初始状态；棋盘上显示 mask/幻化动效与伪装图案。
- [ ] 每次新尝试随机决定幻化方块位置、真实图案与伪装图案；同一 `runSeed` 下完整稳定，不同尝试允许变化。
- [ ] 幻化方块真实图案用于三消、生成验证与解法；伪装图案只用于棋盘视觉，不改变规则。
- [ ] 玩家直接点击幻化方块不失败；方块飞入暂存槽时播放显现动画，并在飞行期间显示真实图案。
- [ ] 显现飞行动画期间占用 1 个暂存槽位并锁定棋盘点击；动画结束后真实图案正式进入暂存槽，再执行三消检查。
- [ ] 飞行、显现、落槽及三消结算完成后恢复棋盘输入；动画期间不得重复点击或触发并发道具动作。
- [ ] 幻化方块无需检测仪也可通过直接点击进入暂存槽并揭示；该行为属于无道具可解路径。
- [ ] 幻化方块视觉与普通方块有明确区分，但不增加必须显示的文字说明。
- [ ] 增加伪装/真实图案、飞行时序、槽位占用、输入锁、重复点击及无道具求解测试。
