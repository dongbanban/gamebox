# 18 — 消磁仪解除磁性

**What to build:** 落地消磁仪目标道具，允许玩家在棋盘上选择可点击的磁吸方块，原位移除磁性而不改变其余棋盘状态。

**Blocked by:** 15 — 消磁仪必须进入 7 种道具集合；17 — 磁吸状态与可点击目标规则必须先存在。

**Status:** done

- [x] 消磁仪基础次数按关卡配置初始化为 1–2 次；磁吸机制压力较高时可按配置档位提高，不读取本次尝试实际磁吸数量。
- [x] 使用消磁仪后只暴露棋盘中可点击的磁吸方块；普通方块、不可点击方块、暂存槽方块与其他机制方块不可选为目标。
- [x] 目标确认前支持取消；取消、无效目标、没有合法目标或次数为 0 时不扣次数、不改变局面。
- [x] 成功后只移除磁性，保留图案、位置、层级、可点击状态与其他机制状态；方块不进入暂存槽、不触发三消。
- [x] 播放原位消磁动效；磁吸静态识别消失，目标恢复普通可点击视觉；动画期间锁定冲突输入。
- [x] 增加次数初始化、目标过滤、取消、无效目标、状态保留、不入槽、不三消、扣次、输入锁与视觉时序测试。
