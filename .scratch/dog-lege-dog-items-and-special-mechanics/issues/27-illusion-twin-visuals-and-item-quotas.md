# 27 — 幻化/双生视觉收口与道具次数规则

**What to build:** 幻化方块、双生方块仅移除棋盘内的特殊动效提示；机制说明缩略图替换为普通方块图，棋盘其他样式、暂存槽视觉与相关动效保留；幻化方块入槽后继续播放显现反馈，双生方块入槽后继续播放分裂反馈；非钥匙道具统一为每关一次。

**Blocked by:** 22 — 规则配置；25 — 游戏运行时边界；26 — 渲染与样式 seam。

**Status:** ready-for-agent

- [ ] 幻化方块仅移除棋盘内的特殊动效；伪装图案、fuzzy、mask、其他样式与动效保留；机制说明缩略图替换为普通方块图。
- [ ] 双生方块仅移除棋盘内的特殊动效；其他样式与动效保留；机制说明缩略图替换为普通方块图，暂存槽视觉不变。
- [ ] 幻化直接点击后先按现有时序飞入暂存槽，入槽完成后再揭示真实图案；检测仪继续支持原位揭示。
- [ ] 双生进入暂存槽后继续播放分裂反馈，并生成两个相邻普通方块；磁吸吸入双生时沿用该反馈。
- [ ] 道具三消移除、容量提升、万能方块、火把、检测仪、消磁仪每关最多成功使用 1 次；取消、无效目标与失败不扣次。
- [ ] 钥匙仍以锁槽数量为本局次数上限，初始 0，按已确认掉落规则增加；钥匙不受统一 1 次限制。
- [ ] 道具摘要、机制说明、保留的样式/动效、入槽反馈与 UI 单测覆盖新规则；删除旧的机制 bonus 次数断言，补充“仅移除棋盘内幻化/双生动效、其他样式动效保留”断言。
