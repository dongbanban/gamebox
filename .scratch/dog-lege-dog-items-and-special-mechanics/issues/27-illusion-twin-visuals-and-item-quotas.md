# 27 — 幻化/双生视觉收口与道具次数规则

**What to build:** 幻化方块、双生方块在棋盘完全使用普通方块视觉：不输出特殊视觉 class，不显示特殊边框/阴影/遮罩、fuzzy、常驻动效或机制图标；幻化伪装图案与机制 data attrs 保留。机制说明缩略图替换为普通方块图，暂存槽视觉与入槽反馈保留；幻化方块入槽后继续播放显现反馈，双生方块入槽后继续播放分裂反馈；非钥匙道具统一为每关一次。

**Blocked by:** 22 — 规则配置；25 — 游戏运行时边界；26 — 渲染与样式 seam。

**Status:** done

- [x] 幻化方块棋盘使用普通方块 class/glyph，不显示特殊边框/阴影/遮罩、fuzzy、常驻动效或图标；伪装图案与机制 data attrs 保留；机制说明缩略图使用普通方块图。
- [x] 双生方块棋盘使用普通方块视觉，不显示特殊边框/阴影、常驻动效或“2”图标；机制说明缩略图使用普通方块图，暂存槽视觉不变。
- [x] 幻化直接点击后先按现有时序飞入暂存槽，飞行期间保持伪装图案且不显现真实图案，入槽完成后再揭示真实图案；检测仪继续支持原位揭示。
- [x] 双生进入暂存槽后继续播放分裂反馈，并生成两个相邻普通方块；磁吸吸入双生时沿用该反馈。
- [x] 道具三消移除、容量提升、万能方块、火把、检测仪、消磁仪每关最多成功使用 1 次；取消、无效目标与失败不扣次。
- [x] 钥匙仍以锁槽数量为本局次数上限，初始 0，按已确认掉落规则增加；钥匙不受统一 1 次限制。
- [x] 道具摘要、机制说明、棋盘普通视觉、入槽反馈与 UI 单测覆盖新规则；删除旧的机制 bonus 次数断言，补充“棋盘不输出幻化/双生特殊 class、fuzzy/mask、常驻动效或图标，机制 data attrs 与入槽反馈保留”断言。
