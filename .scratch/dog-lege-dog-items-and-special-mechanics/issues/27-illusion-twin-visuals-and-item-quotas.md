# 27 — 幻化/双生视觉收口与道具次数规则

**What to build:** 让幻化方块、双生方块在棋盘与机制说明中不再用特殊常驻动效提示，增加判断难度；两类方块进入暂存槽时仍保留必要的揭示/分裂反馈；非钥匙道具统一为每关一次。

**Blocked by:** 22 — 规则配置；25 — 游戏运行时边界；26 — 渲染与样式 seam。

**Status:** ready-for-agent

- [ ] 幻化方块棋盘视觉与普通方块一致，但仍可保留伪装图案；取消 fuzzy、mask、常驻特殊标记与额外必须文字。
- [ ] 双生方块棋盘视觉与普通方块一致；机制说明缩略图使用普通方块图像，不显示双生常驻标记。
- [ ] 幻化直接点击后在飞入暂存槽过程中揭示真实图案；检测仪继续支持原位揭示。
- [ ] 双生进入暂存槽后继续播放分裂反馈，并生成两个相邻普通方块；磁吸吸入双生时沿用该反馈。
- [ ] 道具三消移除、容量提升、万能方块、火把、检测仪、消磁仪每关最多成功使用 1 次；取消、无效目标与失败不扣次。
- [ ] 钥匙仍以锁槽数量为本局次数上限，初始 0，按已确认掉落规则增加；钥匙不受统一 1 次限制。
- [ ] 道具摘要、机制说明、入槽反馈与 UI 单测覆盖新规则；删除旧的机制 bonus 次数与特殊常驻视觉断言。
