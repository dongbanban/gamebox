# 09 — 万能方块

**What to build:** 落地万能方块道具；玩家选择本关图案后，万能方块变为该图案进入暂存槽，并优先帮助冻结方块完成三消。

**Blocked by:** 03 — 需要冻结方块优先级与状态规则；04 — 需要统一道具运行时与目标确认。

**Status:** done

- [x] 使用万能方块后进入图案选择；候选为本关全部图案类型，可重复选择同一图案。
- [x] 最终确认前可以取消；取消不改变棋盘、暂存槽或次数；确认后原子完成图案转换、入槽及棋盘补偿。
- [x] 万能方块进入暂存槽后显示高亮边框或等效视觉标记，与普通同图案方块明确区分。
- [x] 使用时从棋盘不可点击区域减少 1 个所选同图案方块；无可合法减少的方块、会破坏无道具可解性或当前状态不允许时，使用失败且不扣次数。
- [x] 万能方块严格追加到暂存槽末尾；仅追加前槽尾两个连续同图案方块可与万能组成三消，其中冻结方块可优先作为本次连续三消参与者，不跨过其他槽位重排。
- [x] 支持已确认槽尾场景：2 个冻结 + 万能完成三消；1 个冻结 + 1 个普通 + 万能完成三消；未参与三消的普通或冻结方块保留。
- [x] 万能方块只帮助本次三消，不永久融化棋盘中其他冻结方块；三消完成后按现有冻结规则继续。
- [x] 成功使用扣 1 次；道具不会造成失败，执行与三消动画期间锁定输入。
- [x] 增加图案选择取消、棋盘补偿、可解性校验、冻结优先级、视觉标记、次数及原子性测试。
