# 06 — 火把融化冻结方块

**What to build:** 落地火把道具；玩家选择任意冻结方块后将其融化，方块变为普通方块并继续参与当前关卡。

**Blocked by:** 03 — 需要冻结方块状态；04 — 需要统一目标道具运行时。

**Status:** done

- [x] 火把只能选择冻结方块作为目标；目标可以位于棋盘或暂存槽。
- [x] 选择棋盘冻结方块后，方块原位置保留并播放火把/融化特效，完成后变为普通方块，可按普通规则点击。
- [x] 选择暂存槽冻结方块后，冻结状态移除并播放融化特效；状态结算后立即检查三消。
- [x] 火把可作用于任意一个冻结方块；不要求目标满足其他图案或位置条件。
- [x] 目标确认前可以取消；取消、无效目标、次数为 0 不扣次数；成功融化扣 1 次。
- [x] 火把不会直接导致失败；执行期间锁定冲突输入，动画和三消结算完成后恢复。
- [x] 使用火把只是捷径；生成器仍验证不使用火把时的自然融化可解路径。
- [x] 增加棋盘目标、暂存槽目标、取消、扣次、融化后即时三消及视觉时序测试。
