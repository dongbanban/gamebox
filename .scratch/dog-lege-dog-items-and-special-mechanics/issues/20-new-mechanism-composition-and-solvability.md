## V13 current acceptance
- [x] 同一关可同时启用冻结、幻化、磁吸、双生与锁槽；单个方块最多承载一种方块机制，锁槽作为关卡级容量机制独立配置。
- [x] 数量不再沿用旧的低计数 min/max。先按本关逻辑方块总数 `N` 计算特殊机制逻辑单位预算 `floor(N × 0.30)`，再按冻结/幻化/磁吸权重 1、双生权重 2 分配到四类；分配后四类都必须出现，单个方块最多承载一种机制，锁槽仍为 0–2。
- [x] 当前方块规模下，预算落点为：1–5 关 `N=90` → 27 个逻辑单位、各类物理方块约 5–6 个；6–15 关 `N=108–126` → 32–37 个逻辑单位、各类约 6–8 个；16–30 关 `N=144–180` → 43–54 个逻辑单位、各类约 8–11 个；31–99 关 `N=180` → 54 个逻辑单位、各类约 10–11 个。各类数量不能独立取满，生成器必须以总预算为准。
- [x] 总特殊机制密度按逻辑方块单位计算，双生计 2、其他方块机制计 1；v13 上限约为逻辑总数的 30%；锁槽不计入密度，但进入有效容量、无道具求解、难度与预计时长。
- [x] 生成候选真实模拟冻结融化、幻化揭示、磁吸目标、双生分裂、锁槽限制、连续三消与失败边界；不合格候选重抽，受控 fallback 仍必须通过全部验证。
- [x] 无道具可解路径成立：不使用钥匙、消磁仪、扩容或其他道具；锁槽保持上锁，路径可使用基础规则与特殊机制自身行为。
- [x] 相同 runSeed、v13 生成器版本与操作路径复现棋盘、机制、锁槽、磁吸目标与钥匙掉落；磁吸与钥匙使用独立随机流。
- [x] 难度目标提高并覆盖安全选择率、预计时长、槽位压力、机制真实操作成本与误操作风险；目标锚点从第 1 关起进入高压区间，不能回退到 v10 的低压分布。
- [x] 难度锚点按阶段校验：1 关安全选择率 0.18–0.28、预计时长 9–10、压力 0.78–0.98；5 关 0.16–0.24、9.8–10.8、0.80–0.99；6 关 0.15–0.23、10–11.2、0.82–0.99；15 关 0.14–0.22、10.5–11.8、0.84–0.99；16 关 0.13–0.21、11–12.5、0.85–0.99；30 关 0.11–0.19、12–14、0.87–0.99；31–99 关 0.09–0.18、13–16、0.88–0.99。
- [x] 奖励公式保持不变；增加组合、30% 密度、无道具求解、回放、独立随机流、难度边界与 fallback 回归测试。
