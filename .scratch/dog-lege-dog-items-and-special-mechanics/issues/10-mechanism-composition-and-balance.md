# 10 — 多特殊机制组合与难度/次数校验

**What to build:** 让同一关同时承载多种特殊机制，并在生成、求解、道具次数和奖励计算中统一考虑机制密度与难度。

**Blocked by:** 03 — 特殊机制模型与冻结方块；04 — 道具运行时与次数配置；05 — 幻化方块；06 — 火把；07 — 检测仪；08 — 三消移除；09 — 万能方块。

**Status:** ready-for-agent

- [ ] 关卡配置可同时启用冻结、幻化及后续特殊机制；不同特殊机制默认分配到不同方块，不允许单个方块堆叠多种机制。
- [ ] 每种机制独立配置按关卡进度档位解析的 `min/max`，组合后的总特殊方块数量仍满足棋盘容量、总机制密度、三消数量和目标难度约束；具体首版递进曲线由 ticket 14 固化。
- [ ] 特殊机制方块不得出现在底层 `z=0`；候选位置只来自更高层。
- [ ] 至少 70% 的特殊机制方块位于中间层 `0 < z < maxLayers - 1`；剩余方块可位于顶层。
- [ ] 中间层没有合法位置时，候选生成失败并重抽，不得静默把机制方块放到底层。
- [ ] 生成验证同时模拟普通规则、冻结自然融化、幻化直接点击揭示、暂存槽三消、容量限制及所有相关状态迁移。
- [ ] 每个组合关卡至少保留一条无道具可解路径；火把、万能方块、检测仪和其他道具只是捷径，不是唯一解法。
- [ ] 当特殊机制配置的最大值或密度较高时，对应道具次数可以超过基础每关 1–2 次；次数由关卡配置/难度档位决定，不按本次随机实际方块数临时变化。
- [ ] 冻结机制提高时，火把与万能方块对应次数按配置增加；幻化机制提高时，检测仪对应次数按配置增加；其他道具仍按各自配置。
- [ ] 重试、刷新、重新进入未完成关卡时，当前关卡配置下的道具次数规则保持稳定，并生成新的 `runSeed` 及其随机棋盘结果；稳定状态更换道具组时沿用原 `runSeed`、棋盘与特殊方块分布，只重置当前进行中的状态。
- [ ] 随机难度指标、机制密度、预计时长传入现有奖励公式；奖励公式本身不改，重复已完成关卡不产生额外奖励。
- [ ] 增加多机制组合随机回归、层级分布、无道具求解、次数映射、难度边界、奖励输入、seed 复现及无堆叠约束测试。
