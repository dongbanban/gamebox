# 02 — 道具组选择与生命周期

**What to build:** 玩家首次进入游戏时从固定道具集合中选择 3 种道具；之后沿用该组合，也可以在允许时更换并重置当前关卡尝试。

**Blocked by:** 01 — 随机关卡尝试必须先有稳定的尝试边界与 `runSeed` 语义。

**Status:** ready-for-agent

- [ ] 狗了个狗固定提供 5 种道具：道具三消移除、暂存槽容量提升、万能方块、火把、检测仪；首次进入时展示本关棋盘与道具集合，要求选择 3 种不同道具。
- [ ] 选择必须经过最终确认；确认前可以取消或返回修改，确认后才建立当前道具组。
- [ ] 道具组按游戏保存为不透明道具 ID 集合；刷新、离开、再次进入游戏后保留已确认组合，不保存道具效果、次数、棋盘、暂存槽或半状态。
- [ ] 已保存 ID 任一无效时整组失效并要求重新选择；不得静默替换成其他道具。
- [ ] 后续关卡默认顺延首次确认的道具组；编辑页默认勾选当前组合，并要求新组合至少替换一个道具。
- [ ] 在稳定状态、失败结果页、胜利结果页允许更换；目标选择、道具动画或结算期间禁止更换。
- [ ] 稳定状态确认更换后重置当前未完成关卡，但沿用原尝试的同一个 `runSeed`、棋盘与特殊方块分布；只清除当前进行中的通关状态。
- [ ] 失败结果页更换后重试当前关卡；胜利结果页更换后进入下一关；不得回滚已确认的通关、奖励或解锁进度。
- [ ] 选择同一组并取消编辑不重置关卡；更换组合必须有二次确认，取消不产生状态变化。
- [ ] 增加持久化、导航、选择确认、重置语义及 UI 流程测试。
