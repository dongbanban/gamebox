# 07 — 检测仪揭示幻化方块

**What to build:** 落地检测仪道具；玩家选择棋盘中的幻化方块后，在原位揭示真实图案并转为普通方块。

**Blocked by:** 04 — 需要统一目标道具运行时；05 — 需要幻化方块状态与揭示规则。

**Status:** in-progress

- [ ] 检测仪只能选择棋盘中的幻化方块；普通方块、冻结方块、暂存槽方块不可作为目标。
- [ ] 确认目标后锁定棋盘，播放原位检测/揭示动画；不把方块移入暂存槽，不占用槽位，不触发三消。
- [ ] 揭示完成后方块保留在棋盘原位置，真实图案可见，幻化状态移除并转为普通方块；动画结束恢复点击。
- [ ] 目标确认前可以取消；取消、无效目标、次数为 0 不扣次数；成功揭示扣 1 次。
- [ ] 直接点击幻化方块仍按幻化方块规则飞入暂存槽并在飞行中揭示，不要求先使用检测仪。
- [ ] 检测仪不会造成失败；执行期间禁止重复目标选择、普通点击与其他道具动作。
- [ ] 增加目标过滤、原位揭示、槽位不变、无三消、取消、扣次及输入锁测试。
