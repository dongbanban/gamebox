# 04 — 游戏运行时与公共遗留清理

**What to build:** 删除没有消费者的游戏计时/debug 状态和剩余公共遗留，使游戏启动、结果呈现、动画协调和通用游戏契约只保留当前使用的 seam。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 删除 `debug.elapsedMs`、`startedAt`、`endedAt` 及其相关运行时记录和赋值。
- [ ] 删除没有仓内消费者的公共容量/视觉常量、类型别名、单方法控制器类型声明和 no-op 引用。
- [ ] 保留仍被游戏目录、app、动画协调器、渲染器和测试使用的公共入口与契约。
- [ ] 游戏启动、输入锁、动画生命周期、音效、结果回调和游戏目录导航行为保持不变。
- [ ] 现有游戏控制器、渲染器、动画和公共契约测试更新为当前 API 并通过。
