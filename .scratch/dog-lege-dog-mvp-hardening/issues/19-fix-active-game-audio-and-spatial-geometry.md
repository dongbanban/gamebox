# 19 — 修复活动游戏音频初始化与方块空间几何

**What to build:** 修复活动游戏页默认开启音乐却不自动播放、暂存槽图案被裁切、视觉方块覆盖比例与逻辑层叠不一致、底层方块行列过度对齐的问题；同步更新生成器版本、回归测试与前置 ticket 的当前验证描述。

**Related to:** 15 — 收敛活动游戏页视觉与棋盘空间分布；16 — 天空蓝活动页视觉、音乐与 Pages 发布收敛；17 — 收敛游戏目录卡片与愉快音频反馈

**Status:** done

## Acceptance Criteria

- [x] 默认开启音效进入活动游戏页时，在用户点击启动游戏的调用链内初始化并立即尝试播放循环背景音乐；浏览器拒绝自动播放时不阻塞游戏，后续用户操作仍可重试。
- [x] 音效开关关闭、恢复、销毁与持久化行为不回归。
- [x] 暂存槽已放入方块完整显示图案；图案资源、底色、边框、阴影与棋盘方块保持同一视觉语义。
- [x] 普通渲染方块盒与 `4×4` 逻辑方块同步，不再使用独立的面积放大或 z 轴二维平移破坏 `1/2`、`1/4` 可见覆盖比例。
- [x] 底层 `z=0` 摆放使用多个半方块细网格相位，x/y 不再全部落在同一个 4 格相位；同层无正面积重叠、跨层几何硬约束与可解性保持。
- [x] 摆放算法变更将生成器版本从 5 升至 6；同一版本、游戏身份、关卡号、base seed 与 test seed 可稳定重放。
- [x] 回归测试覆盖音乐启动、暂存槽图案完整盒、可见覆盖比例与底层相位分布；ticket 验证记录实际命令与结果。

## Implementation Notes

- 音乐初始化放在游戏 `start()`，不是依赖第一次选择方块或手动切换开关；`HTMLAudioElement.play()` 失败只视为可恢复的浏览器媒体限制。
- 视觉方块恢复为逻辑盒尺寸，移除与层叠关系无关的二维 z 平移；层级仍由 `z-index`、禁用态与阴影表达。
- 底层候选锚点合并四个 `4×4` 方块内的半方块相位，再沿用同层碰撞、遮挡上限、区域分布、重叠比例与可解校验。
- 旧 ticket 15、16、17 保留原编号；本 ticket 作为最新 follow-up，修正已完成 ticket 中被后续代码覆盖的面积、音乐初始化与验证表述。
