# 15 — 收敛活动游戏页视觉与棋盘空间分布

**What to build:** 根据最新视觉反馈收敛活动游戏页顶部控制、信息密度、暂存槽与棋盘尺寸；隐藏关卡选择 UI 但保留已解锁关卡重玩逻辑；在不改动前期难度与可解主流程的前提下，增强棋盘方块的中心/四角空间分布与区域层叠关系；同时按功能整理狗了个狗源码目录，减少文件平铺。

**Blocked by:** 11 — 精简游戏目录与游戏页控制区；12 — 完成移动端无滚动游戏布局

**Status:** in-progress

本 ticket 的视觉决策覆盖 ticket 11 中“音效开关位于关卡选择区域”和“关卡号、剩余方块、图案数量、层数继续显示”的旧展示约束；ticket 12 只提供移动端视口布局基础，关卡选择与音效位置以本 ticket 为准。

## Acceptance Criteria

- [ ] 活动游戏页不渲染游戏名称；GAMEBOX logo 保留。
- [ ] 返回目录按钮位于左上角 GAMEBOX logo 左侧，只保留返回图标；按钮继续拥有“返回游戏目录”可访问名称与足够点击区域。
- [ ] 音效开关位于右上角，以音乐图标表达开启/关闭状态；保留可访问名称、`pressed` 等价状态语义、持久化与刷新恢复；下方不再渲染重复音效按钮。
- [ ] 活动游戏页不生成关卡选择区域 DOM；代码逻辑仍允许通过既有导航/启动 seam 重玩已解锁历史关卡，且不能绕过线性解锁校验。
- [ ] 第一关不渲染右侧剩余方块、图案类型与层数三项统计；这些字段仍可保留在内部局内状态、调试信息或测试 seam 中。
- [ ] 暂存槽中的已放入方块与棋盘方块共享图案资源、底色、边框、阴影与层次视觉语义；空槽仍能表达可用位置。
- [ ] 移动端活动视口中棋盘面积与方块可见面积相对当前布局增大；方块点击目标同步增大，棋盘与完整 7 格暂存槽仍无需滚动、拖拽或缩放即可操作。
- [ ] 棋盘保留背景色，移除可见网格线；内部逻辑网格仍可用于坐标、摆放与测试。
- [ ] 关卡生成继续使用当前前期方块数量、图案阶段、难度目标、可解搜索与安全选择主逻辑；本 ticket 不以降低难度或放宽几何硬约束解决布局问题。
- [ ] 每个代表性生成关卡的方块分布满足：中心区方块数量占多数，左上/右上/左下/右下四角区各有非零少量方块；区域数量不要求相等，且由关卡号与 seed 稳定决定。
- [ ] 每个非空区域都存在区域内跨层正面积遮挡；代表性样本中存在跨区跨层遮挡，区域之间不被硬隔离成五个互不关联的堆。
- [ ] 空间分布调整继续满足既有不规则轮廓连通、方块位于棋盘形状内、同层无正面积重叠、`1/4`/`1/2` 部分重叠比例、完全对齐上限、下层遮挡上限与无道具可解约束。
- [ ] 摆放算法改变提升生成器版本；同一新版本、游戏身份、关卡号与显式 seed 可稳定重放同一棋盘、图案、区域分布与层叠关系。
- [ ] `src/games/dog-lege-dog/` 按功能分组，至少形成以下目录：`assets/` 存放 `animation-effects.ts`、`game-assets.ts`、`particle-effects.ts`、`sound-effects.ts`；`game/` 存放 `game-config.ts`、`game-controller.ts`、`game-renderer.ts`、`game-session.ts`、`game-types.ts`；`levels/` 存放 `first-level.ts` 与全部 `level-*.ts` 生成、规则、图案、回放和难度文件。
- [ ] 根目录 `src/games/dog-lege-dog/index.ts` 保持游戏入口职责与现有外部导入 seam；移动文件后所有相对路径、测试导入与构建入口更新正确，不新增散落的重复实现。
- [ ] 文件结构整理不改变游戏运行行为、DOM seam、关卡生成结果、生成器版本、游戏进度或公开 API；目录命名与职责边界在 ticket 实现说明中记录。

## Implementation Notes

- 使用与当前棋盘相同的方块渲染语义渲染暂存槽，区分“空槽”和“已放入方块”，不复制一套低对比占位卡片样式。
- 顶部控制布局只改变活动游戏页 UI；游戏目录仍可展示游戏名称，历史关卡启动与游戏进度模型不因移除关卡选择 DOM 而删除。
- 区域可以按棋盘逻辑坐标划分为中心区与四角区。中心区需要占多数，四角区保持少量；不要用固定等量或规则网格重新制造紧凑方阵。
- 在既有合法消除路径/候选摆放之后加入区域分布约束。候选失败时做确定性重试或 fallback，不降低 `1/4`/`1/2` 重叠、同层不重叠、遮挡上限或可解性硬约束。
- 区域内层叠与跨区层叠均基于正面积交集；边/角接触不算遮挡。测试 oracle 独立计算区域归属与交集。
- 文件结构按三层职责整理，建议保持以下布局：

  ```text
  src/games/dog-lege-dog/
  ├── index.ts
  ├── assets/
  ├── game/
  └── levels/
  ```

  `assets/` 只放图案、音效与动画资源；`game/` 只放局内状态、控制器、渲染器与游戏配置；`levels/` 只放关卡类型、生成、摆放、规则、难度、回放与奖励逻辑。不要为单个文件继续创建更深层目录。
- 移动文件后优先统一 import 路径与 barrel/entry 导出，再运行类型检查；不通过复制旧文件或保留两份实现兼容旧路径。
