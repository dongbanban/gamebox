# 05 — 生成首个不规则部分重叠关卡

**What to build:** 将第 1 关替换为稳定、可解的不规则棋盘，使首关明显展示面积为 `1/4` 与 `1/2` 的部分遮挡，并增加图案种类。

**Blocked by:** 01 — 拆分关卡生成器深模块；02 — 共享层叠关系图并收敛局内快照

**Status:** done

- [x] 第 1 关通过统一生成器与首关配置创建，不再使用独立硬编码长方形布局。
- [x] 方块使用 `4×4` 细网格、整数 `x/y/z`、不旋转，支持四分之一方块精度。
- [x] 棋盘可玩区域连通，具有至少两个非对称凹口或突出部，不退化为规则图形。
- [x] 第 1 关保持 90 个方块、最多 3 层、稳定 seed、稳定重放与无道具可解路径。
- [x] 第 1 关使用 6 种无重复图案类型，每种图案总数为 3 的倍数。
- [x] 跨层重叠关系中至少 70% 为方块面积的 `1/4` 或 `1/2`。
- [x] `1/4` 与 `1/2` 重叠各自至少占首关跨层重叠关系的 20%。
- [x] 完全对齐的跨层重叠不超过 10%；同层无正面积重叠；单个下层方块最多被 4 个上层方块遮挡。
- [x] 使用独立几何 oracle 验证相交面积比例与轮廓合法性。
- [x] 真实浏览器可完成首关并显示正确棋盘、暂存槽、通关与失败结果。

## Comments

- 首关接入统一 `DogLevelProvider`/`GeneratedLevelGenerator`；生成器版本升级为 v3；首关模板、图案、数量、层数与摆放参数集中在游戏配置。
- 首关棋盘扩展为 4×4 细网格，90 个方块、3 层、6 种图案；固定 seed 可 replay；首关无 fixed layout/replay 分支。
- 新增独立几何 oracle：连通性、凹口/非对称、方块在轮廓内、同层无重叠、遮挡上限、1/4 与 1/2 交集比例。
- 验证通过：`pnpm typecheck`、`pnpm build`、`pnpm test:core`（54 tests）、`DOG_RANDOM_LEVEL_COUNT=3 DOG_STRESS_LEVEL_COUNT=100 pnpm test:random`（3 tests）、`pnpm test:e2e`（12 tests）。
