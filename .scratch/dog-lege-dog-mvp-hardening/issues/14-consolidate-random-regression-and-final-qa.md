# 14 — 收敛随机回归与最终 QA 契约

**What to build:** 用可重放的跨阶段随机回归和完整浏览器流程验证 hardening 后的棋盘、难度、奖励、导航、离开保护、布局与持久化闭环，并收敛重复测试辅助逻辑。

**Blocked by:** 06 — 扩展全部无限不规则关卡；07 — 修复安全选择三态搜索与难度筛选；08 — 按关卡难度发放通关奖励；09 — 通关后直接进入下一关；10 — 统一活动关卡离开保护；11 — 精简游戏目录与游戏页控制区；12 — 完成移动端无滚动游戏布局；13 — 拒绝语义损坏的游戏进度

**Status:** ready-for-agent

- [ ] 未显式提供 test seed 时，每次常规随机回归创建并输出新的 test seed。
- [ ] 同一次运行的关卡选择、生成与报告全部由记录的 test seed 驱动。
- [ ] 常规随机回归生成 1–100 个跨阶段采样关卡，不只覆盖从第 1 关开始的连续前缀。
- [ ] 固定覆盖第 1、5、10、15、30、100 关，并保留 100–1000 关压力档。
- [ ] 失败报告包含 test seed、关卡号、关卡 seed、生成器版本与单关重放命令。
- [ ] 属性测试覆盖不规则轮廓、`1/4`/`1/2` 重叠、完全对齐上限、图案阶段、可解性、安全选择三态与难度筛选。
- [ ] 浏览器流程覆盖注册、目录、重置、游戏、通关奖励、下一关、失败、重试、返回、后退、刷新、关闭、音效与移动布局。
- [ ] 内存 storage、不可用 storage、几何 oracle、首关通关驱动与浏览器助手统一复用。
- [ ] 测试不验证私有函数、模块调用次数、具体 CSS 属性或动画帧。
- [ ] TypeScript typecheck、生产构建、核心测试、随机回归、Chromium E2E 全部通过。
- [ ] Safari（Playwright WebKit）与移动 Chromium smoke 配置可列出并按环境能力运行。
