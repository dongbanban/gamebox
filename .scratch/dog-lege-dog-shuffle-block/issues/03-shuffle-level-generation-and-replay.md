# 03 — 乱序正式关卡生成、求解与回放

**What to build:** 将安全乱序接入正式关卡。第 3 关起生成乱序方块，第 1–2 关保持现有四类特殊机制。启用乱序的关卡每关最多生成 1 个，继续支持现有锁槽；机制预算、动态阈值、无道具可解、难度筛选、随机回归与回放全部使用同一规则。

**Blocked by:** 02 — 安全乱序与二次结算

**Status:** ready-for-agent

- [ ] 第 3–99 关按配置启用乱序，第 1–2 关不生成乱序方块；启用关卡每关最多 1 个乱序方块。
- [ ] 乱序方块按 1 个逻辑单位计入 30% 特殊机制预算，现有冻结、幻化、磁吸、双生的全类型约束继续有效。
- [ ] 启用乱序的关卡继续按现有规则生成 0–2 个锁槽；有效容量为 5、6、7、8 时乱序阈值分别为 3、4、5、5，容量提升道具可将总容量提高到 8。
- [ ] 生成器发布候选前验证机制组合、结构、无道具通关路径、乱序触发路径与难度目标；复原哨不是可解性前提。
- [ ] 求解器与运行时共享同一安全候选、二次三消、容量与终局语义，不重置磁吸或钥匙随机流。
- [ ] 相同 `runSeed` 完整复现棋盘、乱序事件与回放；不同 `runSeed` 可产生不同且通过验证的尝试。
- [ ] 机制说明、生成配置、测试 profile、动态阈值边界、随机回归与正式关卡 UI 覆盖第 3 关启用边界；完成前运行 `pnpm test:qa`。
