# 03 — 乱序正式关卡生成、求解与回放

**What to build:** 将安全乱序接入正式关卡。第 3 关起生成乱序方块，第 1–2 关保持现有四类特殊机制。启用乱序的关卡每关最多生成 1 个，继续支持现有锁槽；机制预算、动态阈值、无道具可解、难度筛选、随机回归与回放全部使用同一规则。

**Blocked by:** 02 — 安全乱序与二次结算

**Status:** done

- [x] 第 3–99 关按配置启用乱序，第 1–2 关不生成乱序方块；启用关卡每关最多 1 个乱序方块。
- [x] 乱序方块按 1 个逻辑单位计入 30% 特殊机制预算，现有冻结、幻化、磁吸、双生的全类型约束继续有效。
