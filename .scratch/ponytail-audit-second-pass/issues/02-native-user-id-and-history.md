# 02 — 使用浏览器原生身份与历史能力

**What to build:** 在不改变注册、游戏进度恢复、临时运行模式和导航体验的前提下，使用浏览器原生 UUID 与 History 行为替代手写回退和冗余 URL 拼装，并删除已被 99 关边界提前拒绝的旧历史分支。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 新匿名用户直接使用 `crypto.randomUUID()`，删除手写随机 UUID 和字节格式化回退。
- [ ] 持久化与注入用户 ID 的 UUID 校验继续保留，无效值仍按当前行为拒绝或替换。
- [ ] 注册、回访、损坏存储、不可用存储与写入失败行为保持不变。
- [ ] History 状态更新省略冗余当前 URL 参数，游戏目录、活动关卡、返回和浏览器后退行为保持不变。
- [ ] 删除在最高关卡已限制为 99 后永远不可达的旧完成历史上限及对应误导性测试表述。
- [ ] 使用现有游戏进度与应用导航行为测试验证结果，不新增生产测试 seam。
- [ ] 运行本范围要求的验证并记录结果；最终批量 QA 关联 ticket 10。
